# ✈️ 독수리 편대

> 복엽기를 조종해 쏟아지는 적기를 격추하라! 폭탄과 롤 회피로 32스테이지를 돌파!

**▶ 지금 바로 플레이** → [https://mindweaver74.github.io/1942](https://mindweaver74.github.io/1942)

---

## 🎮 게임 방법

1. 복엽기를 조종해 위에서 내려오는 적기를 격추하세요
2. 폭탄으로 화면 전체를 공격하거나, 롤 회피로 적의 공격을 피하세요
3. 보조기를 획득하면 화력이 증가합니다
4. 32스테이지를 모두 클리어하면 승리!

---

## 🕹️ 조작법

| 환경 | 이동 | 폭탄 | 롤 회피 |
|------|------|------|---------|
| PC | 방향키 | Z 키 | X 키 |
| 모바일 | 화면 드래그 | 폭탄 버튼 | 롤 버튼 |

---

## ✨ 주요 특징

- ✈️ **보조기 시스템** — 최대 2기 편대 비행, 화력 3배
- 💣 **폭탄** — 최대 9개 보유, 화면 전체 공격
- 🔄 **롤 회피** — 적탄을 무적으로 회피
- 👾 **32스테이지** — 스테이지마다 강화되는 적과 보스
- 🎵 **효과음** — 발사·격추·폭발 효과음

---

## 💡 고득점 전략

- 보조기를 최대 2기까지 유지하세요 — 화력이 크게 올라갑니다
- 폭탄은 보스전이나 포위당했을 때 아껴두세요
- 롤 회피는 쿨타임이 있으니 타이밍을 잘 맞추세요
